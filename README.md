# Portfolio — Acile Harb

Site statique (HTML + CSS), hébergé sur GitHub Pages.

## Ajouter un projet resto
1. Duplique `projets/_modele-resto.html` et renomme-le (ex. `projets/nom-du-resto.html`).
2. Remplace les textes, et les images/vidéos (attribut `src`). Mets tes fichiers dans `assets/img/`.
3. Dans `index.html`, copie un bloc `<a class="work-item">` dans « Selected work » et fais-le pointer vers ta nouvelle page.

Ou demande simplement à Claude de le faire.
